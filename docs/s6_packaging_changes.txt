PESTFLY repository review: Step 5
Supplementary File S6
5 October 2026

COMPLETED

PESTFLY_Supplementary_File_S6.zip contains all seven supplementary analyses,
their scripts, parameter and run records, summary tables, figures and complete
outputs, with core metadata, QC and SNP resources for context and reproduction.
It has 1182 files and is approximately 77.08 MiB.

The nine page PDF reader guide explains each analysis, its recorded findings,
metric denominators, limitations and reproduction prerequisites. source_map.tsv
maps eleven sections and resources to their scripts and key outputs.

Complete baseline query trajectories are included for every evaluated SNP
subset: 352 P1 rows for 22 queries, 192 P2 rows for 12 queries and 112 P3 rows
for seven queries. All 656 rows are retained, with 16 K values per evaluated
query branch. Low K rows and missing posterior values remain visible. Three
failed macroregion queries have no evaluated conditional subregion branch.

PRESERVATION AND EXPORT COPIES

All numerical TSV, RDS, Excel, PDF figure and compressed output files are byte
identical to the preceding checkpoint. Six summary text files received ten
presentation replacements. Their numerical lines and all other bytes were
preserved. Exact replacements and before and after hashes are recorded in
docs/textual_output_changes.tsv. Original text is retained in earlier

15,666,945 redundant bytes and are mapped in duplicate_exports.tsv. Complete
scenario outputs and every distinct result remain included. The full repository
checkpoint retains the export copies.
