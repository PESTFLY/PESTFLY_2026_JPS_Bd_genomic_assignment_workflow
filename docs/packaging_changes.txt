Changes completed
1. Retained eight core scripts, public metadata, core results and all seven
   supplementary validation scripts and result groups.
2. Moved supplementary analyses to steps/validation and results/validation.
   The reference exclusion result folder is results/validation/07_exclusion.
   This shorter result name accommodates nested scenario paths on Windows.
3. Standardised the challenge script filename as run.R for case sensitive
   filesystems.
4. Corrected old script execution examples, displayed step numbers and public
   validation labels. Earlier compatible option identifiers and output
   basenames remain in use by the scripts.
5. Rebased 87 location cells in 22 archived TSV index tables. Only location
   columns changed. Step 02 panel_dir fields are relative to the index folder;
   other adapted index paths are relative to the repository root. Future
   Step 02 indexes also write relative panel paths.
6. Added a separate runner for the seven supplementary analyses and concise
   guides to the repository, data, results and validation directories.
7. Excluded the 276 MiB generated sample_missingness.tsv from this copy. Its
   RDS counterpart and other QC outputs are retained. The original uploaded
   revision archive preserves the excluded TSV.
8. Excluded local session, editor and incidental plotting files. The package
   is a clean directory copy and does not contain local repository history.
